## 一、状态机

```
S0 星图
  │ 点星核（命中半径 24px）
  ▼ 0.2s 定格 + 2.0s 整体缩小
S1 ∞ 徽标（172px，居中）
  │ 悬停 1.2s 光扫外环（每圈）；单击 → S1' 选中态
  ▼ 再单击，0.6s 展开
S3 规则区（星图降到 15% + blur(6px)）
  │ ESC / 点空白：先回 S1'，再回 S1，再回 S0
```

## 二、幕一：定格 + 整体缩小（甲）

1. **定格** 0.2s：星带流动、自动旋转、星尘闪烁全部冻结（`flowRate → 0`，不再推进时间）
2. **缩小** 2.0s：整块画布绕视口中心做 `scale 1 → 0.112`（172 / 1536），星云与星带一起缩；缓动 `cubic-bezier(0.5, 0, 0.2, 1)`
3. **∞ 接管**：缩小到 40% 时（约 0.8s 处）∞ 从 `alpha 0 / scale 0.7` 淡入并展开，到 100% 时完全覆盖
4. 缩小过程中禁用拖拽、滚轮、点击

技术要点：∞ 与星图同画布绘制，避免 DOM 与 canvas 的尺寸/位置不同步。
形状对不上的风险用两件事缓解：缩小到 40% 时星带已只剩中心一团光核，∞ 从这团光核里长出来；∞ 的粒子前 0.4 秒从星核位置向外扩散，视觉上承接。

## 三、∞ 的渲染

- 骨架：三条贝塞尔曲线（粉紫 `#c86bff`、青 `#5fe6ff`、黄 `#fff08a`），线宽 1.2px
- 沿曲线撒粒子 6000 颗，速度 0.02/秒，颜色分段渐变，带轻微抖动
- 交点：径向白核（r=14px）+ 12 条放射线（长 26px、alpha 0.5、呼吸）
- 外环：24 段金色刻度，未选中 alpha 0.25
- 标题：下方 24px「记忆星图」，字距 6px，上下细线 + 前置圆点

## 四、幕二：悬停与选中

悬停（预览态）：
- 60° 锥形高光沿外环转一圈 **1.2s**，扫过的刻度 alpha 0.25 → 0.9，离开后回落
- 星核亮度 1 → 1.35，横向炫光 180 → 240px
- 整体 `scale 1.0 → 1.03`，光标 pointer

单击（选中态）：
- 外环刻度常亮 alpha 0.8，徽标上浮 6px，标题变亮
- 选中期间光扫放慢到 2.4s/圈，作为"待确认"的暗示

## 五、幕三：规则区

| 区域 | 内容 |
| --- | --- |
| 顶栏左 | 「记忆星图 · 规则」 |
| 顶栏中 | 标签：**主规则**（钉住）+ 6 个工作区，横向滚动 |
| 顶栏右 | 保存 / 重置 |
| 进度条 | 已加载文件 N / M（真实值，不用假的 0%） |
| 中段 | 文件柜：一块竖玻璃板 = 一个 AGENTS.md |
| 下段左 | 选中文件的 `##` 小节列表 |
| 下段右 | 小节正文；默认只读，「编辑」切换为可写 |

细节：

- 有文件：文件名、大小、mtime；无文件：虚框「未创建」，点击新建（内容一行 `# <工作区名> · 规则`）
- 竖板选中：外发光 24px、青色边框、抬升 6px、引线连到上方标签
- 主规则那块加"全局"角标，工作区那块加"仅本区"角标——把分级写进视觉
- 没有 `##` 的文件：整篇当一节
- mtime 在 24 小时内的文件/小节挂「新」角标

## 六、数据与接口

工作区路径从会话记录的 `cwd` 取（目录名反推有歧义）。

```
GET  /mobius/api/rules
     → { main: {path, exists, size, mtime, sections[]},
         workspaces: [{cwd, name, path, exists, size, mtime, sections[]}] }
GET  /mobius/api/rules/file?path=     → { path, mtime, content }
POST /mobius/api/rules/file           → { path, mtime, content, create? }
```

安全：

- 白名单：只允许 `~/.dsh/AGENTS.md` 与已发现工作区根目录下的 `AGENTS.md`
- 写前备份 `AGENTS.md.bak-<时间戳>`
- mtime 不一致 → 409，前端提示「文件已被别处修改」并重载
- 写操作只对 loopback 开放

## 七、验收标准

1. 点星核 0.2s 内定格，2.0s 内整块星图缩到 172px，中心误差 < 2px
2. 缩小到 40% 时 ∞ 开始淡入，结束时无可见接缝
3. 悬停 1.2s 内光扫一圈，刻度依次点亮，整体放大到 1.03
4. 单击进入选中态，再单击展开；顶栏 7 个标签可横向滚动，主规则不动
5. 6 个工作区里 5 个显示「未创建」，点击能建出只有一行标题的文件
6. 默认只读；点「编辑」后可改；保存后磁盘一致且留有 `.bak`
7. 外部改动后保存 → 409 + 提示重载
8. ESC 逐层退出回星图

## 八、风险

- 5 个空工作区会让文件柜显得稀，需要给虚框一个统一暗纹
- 缩小动画期间若用户狂点，要拦住（状态机加锁）
- 大文件（>100KB）渲染性能
- 编辑 AGENTS.md 会影响下一轮对话行为，需二次确认
