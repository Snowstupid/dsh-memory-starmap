# 规则区（三幕）实现规格 v0.1

> 需求来源：2026-11-06 的三张参考（∞ 光带、悬停录屏、规则区界面截图）。
> 本文是实现前的对齐稿，参数都可以改。

## 一、状态机

```
S0 星图
  │ 点击星核（命中半径 24px）
  ▼ 2.2s 凝缩
S1 ∞ 徽标（172px，屏幕正中，纯装饰，不再承载记忆星）
  │ 悬停 1.2s 光扫外环
  ▼ 单击
S1' 选中态（外环常亮、上浮 6px、标题变亮）
  │ 再单击
  ▼ 0.6s 展开
S3 规则区（星图降到 15% 亮度 + blur(6px)）
  │ ESC / 点空白
  ▼ 0.45s 收起
S1' → S1 → S0
```

## 二、幕一：凝缩

- 时长 **2.2s**，缓动 `cubic-bezier(0.16, 1, 0.3, 1)`
- 星带：`dist 5.9 → 2.6`；全部星点 alpha 乘 0.15；u 向交点方向收拢（沿弧长聚到 t=0）
- 记忆星：alpha → 0（不参与 ∞）
- ∞ 光带：后 40% 时间从 `scale 0.2 / alpha 0` 展开到 `scale 1 / alpha 1`
- 落点：视口正中，**固定 172px 宽**（= 徽标 86×2）
- 背景：星云压到 60% 亮度

## 三、∞ 的渲染

- 骨架：**三条**贝塞尔曲线（粉紫 `#c86bff`、青 `#5fe6ff`、黄 `#fff08a`），线宽 1.2px
- 沿曲线撒粒子 **6000** 颗，速度 0.02/秒，颜色按曲线分段渐变，粒子带轻微抖动
- 交点：径向白核（r=14px）+ **12 条**放射线（长 26px、alpha 0.5、随时间呼吸）
- 外环：24 段金色刻度，未选中 alpha 0.25
- 标题：下方 24px 处「记忆星图」，字距 6px，上下两条细线 + 前置小圆点

## 四、幕二：选中态动效

- 光扫：60° 锥形高光，**1.2s 转一圈**；扫过的刻度 alpha 0.25 → 0.9 并保持一小段再回落
- 星核：亮度 1 → 1.35，横向炫光 180 → 240px
- 整体：`scale 1.0 → 1.03`，光标变 pointer
- 移出：300ms 反向回落

## 五、幕三：规则区

布局（对齐参考图）：

| 区域 | 内容 |
| --- | --- |
| 顶栏左 | 「记忆星图 · 规则」 |
| 顶栏中 | 标签：**主规则** + 各工作区（横向滚动） |
| 顶栏右 | 保存 / 重置 |
| 进度条 | 已加载文件 N / M（不用假的 0%） |
| 中段 | 文件柜：一块竖玻璃板 = 一个 AGENTS.md |
| 下段左 | 选中文件的 `##` 小节列表（序号 + 标题 + 「新」角标） |
| 下段右 | 小节正文（只读展示 / 编辑切换 / 保存） |

细节：

- 有文件：显示文件名、大小、mtime
- 无文件：虚框「未创建」，点击 = 新建并写入模板
- 竖板选中：外发光 24px、青色边框、抬升 6px、引线连到上方标签
- 列表项选中：右侧内容区 200ms 淡入，并滚到对应小节
- 没有 `##` 的文件：整篇当一节
- 「新」角标：mtime 在 24 小时内的文件/小节

## 六、数据与接口

工作区路径从会话记录的 `cwd` 取（目录名反推有歧义）。

```
GET  /mobius/api/rules
     → { main: {path, exists, size, mtime, sections[]},
         workspaces: [{cwd, name, path, exists, size, mtime, sections[]}] }

GET  /mobius/api/rules/file?path=      → { path, mtime, content }
POST /mobius/api/rules/file            → { path, mtime, content, create? }
```

安全：

- 路径白名单：只允许全局 `~/.dsh/AGENTS.md` 与已发现工作区根目录下的 `AGENTS.md`
- 写前备份为 `AGENTS.md.bak-<时间戳>`
- `mtime` 不一致 → **409**，前端提示「文件已被别处修改」并重载
- `create: true` 时文件不存在也允许创建

## 七、验收标准

1. 点星核 2.2s 内凝缩成 172px ∞，中心坐标误差 < 2px
2. 悬停 1.2s 内光扫一圈，刻度依次点亮，整体放大到 1.03
3. 单击进入选中态，再单击展开，面板内出现主规则 + 6 块工作区竖板
4. 5 个空工作区显示「未创建」，点击能建出文件
5. 编辑保存后磁盘内容与界面一致，且留有 `.bak`
6. 外部改动后保存 → 409 并提示重载
7. ESC 逐层退出，回到星图

## 八、风险与未定

- 6 个工作区里 5 个是空的，文件柜会比较空，需要给空块一个统一插画或暗纹
- 写工作区文件是否需要额外授权（沙箱策略里工作区是可写的，但项目 root 未必）
- 大文件（>100KB）的渲染与编辑性能
- 凝缩过程里原有交互（拖拽/缩放）要禁用，避免状态打架
