# 给 AI 助手：帮用户安装「记忆星图」插件

> 这份文件是写给**你（AI 助手）**的。用户把压缩包丢给你，说“帮我装这个”，按下面的步骤做。
> 每一步都写清楚了命令和预期结果；跑不通就照最后一节排查，不要凭猜测下结论。

---

## 一、先向用户介绍这是什么（30 秒版）

**dsh-memory-starmap / 记忆星图** 是 DSH 的插件，给 DSH 加三样东西：

1. **侧栏「记忆星图」** —— 把 DSH 的历史对话画成一条星带。
   每条对话是一颗星，按工作区分组，可以拖拽旋转、滚轮缩放、搜索、点开看全文。
2. **规则区（叫「如我所书」）** —— 一个界面，可视化地读写你的 `AGENTS.md`：
   全局的 `~/.dsh/AGENTS.md`，以及每个工作区自己的 `AGENTS.md`，能改、能存、存前自动备份。
3. **给模型用的记忆检索工具 `mobius_recall`** —— 模型可以主动“翻旧账”：
   “我们之前定过什么”“上次那个 bug 怎么修的”，返回带日期和“谁说的”的原文摘录。

特点：纯本地，不联网，数据只读 `~/.dsh/sessions`；零依赖；索引冷建约 1 秒。

## 二、安装（Windows，桌面端 profile）

假设压缩包解压到 `C:\Users\<用户>\Downloads\starmap\`，里面应有三个文件：

```
dsh-memory-starmap-0.2.0.tgz
先读我-AI 安装说明.md      ← 本文件
人类版说明.txt
```

### 步骤 1：把 tgz 放到一个不会被删的地方

建议 `C:\Users\<用户>\dsh-plugins\`。**不要放在 Downloads 里装完就删**——这个路径会被记进 profile 的 package.json。

### 步骤 2：安装包

```powershell
dsh plugin --profile desktop add file:C:\Users\<用户>\dsh-plugins\dsh-memory-starmap-0.2.0.tgz
```

预期：pnpm 输出 `+ dsh-memory-starmap 0.2.0`。

> 桌面端如果提示“找不到 dsh 命令”，改用在 DSH Desktop 里打开终端，或直接用完整路径调用 node。

### 步骤 3：让它真正被加载（关键，别跳过）

`dsh plugin add` 只是把包装进 `node_modules`，**不会**写进加载列表。少了这步，包在那儿但不会加载，侧栏什么都不会出现。

```powershell
node C:\Users\<用户>\.dsh\profiles\desktop\node_modules\dsh-memory-starmap\bin\enable.mjs desktop
```

预期输出：`desktop: 已把 dsh-memory-starmap 加进 dsh.profile.bundles`

它会先备份 profile 的 `package.json`，重复跑是幂等的。

**替代做法**：如果用户想用 GUI，让他打开「设置 → 插件 → 添加」，填 tgz 的路径。GUI 那条路会自动写加载列表，不用跑第 3 步。

### 步骤 4：重启 DSH 桌面端

完全退出再打开（不是关窗口）。宿主侧的路由和工具是在启动时注册的。

### 步骤 5：验证

1. 侧栏出现「记忆星图」图标（翁法罗斯徽记/∞ 那个）
2. 点开能看到星带、星星、左下角工作区分组
3. 点正中星核 → 星图会凝缩成一枚 ∞ 徽标
4. 再点一次 → 展开「如我所书」规则区，能看到主规则和各工作区

四条都对，就是装好了。

## 三、教用户怎么用

### 星图

- 拖拽：旋转；滚轮/双指：缩放；双击：复位
- 点一颗星：右侧出全文、来源会话、日期，以及和它相关的 8 条
- 右上搜索框：输入关键词，命中的星会套光环
- 左下角：按工作区分组，点一下可以隐藏那一组
- 点开的星右侧有「不再显示」和「改概要」，是本地覆盖层，随时能恢复

### 如我所书（规则区）

- 从 ∞ 徽标再点一次进入，或按 ESC 逐层退回
- 顶栏 7 个标签：主规则 + 各工作区，横向可滚
- 竖板 = 一份 `AGENTS.md`，没文件的显示「未创建」，点「编辑」可新建
- 默认只读，点「编辑」才能改；保存前自动备份成 `AGENTS.md.bak-<时间戳>`
- 如果文件被别处改过，保存会提示冲突并重新载入，不会覆盖

### 模型侧工具

装好之后，DSH 的模型会自动多一个 `mobius_recall` 工具和一行系统提示词。
用户直接问“我们之前是怎么定这个的”，模型就会去查。

不想让它参与，设置环境变量 `MOBIUS_TOOL=0` 再重启。

## 四、排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 侧栏没有图标 | 没写进 `dsh.profile.bundles`，或没重启 | 跑第 3 步，再重启 |
| 打开星图一片黑 | 索引还没建好 | 等 2 秒；或看控制台 |
| 规则区显示红色「读取失败」 | 宿主没重启，接口没注册 | 重启 DSH |
| 插件列表里看不到它 | 同上 | 同上 |
| 版本装错了 | pnpm 按版本号缓存 | 装新版必须换文件名（tgz 带版本号） |

## 五、卸载

```powershell
dsh plugin --profile desktop remove dsh-memory-starmap
```

然后从 `C:\Users\<用户>\.dsh\profiles\desktop\package.json` 的 `dsh.profile.bundles` 里删掉 `"dsh-memory-starmap"` 这一行，重启。

用户自己的数据在 `~/.dsh/mobius-memory.json`（隐藏的星、改过的概要），删不删都行，不影响运行。

---

## 六、给 AI 的几条提醒

- 不要替用户编造“已经装好了”。每一步都要真跑，跑完看输出。
- 装完一定要做第 5 节的四条验证，别只看命令返回成功。
- 用户的数据（会话、AGENTS.md）都在他自己机器上，**不要**上传或转发。
- 这个插件只读会话文件，不会修改历史；唯一会写的是 `mobius-memory.json`（覆盖层）和用户在规则区主动保存的 `AGENTS.md`。
